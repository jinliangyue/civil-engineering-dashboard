# 数据输入规范（用户必读）

> 这是你下载完数据后整理 CSV 文件的标准。Claude Code 收到后会自动处理。

---

## 1. 文件命名规范

把每种材料的月度价格数据保存为一个 CSV 文件，文件名格式：

```
<材料名>_<地区代码>_<起始年月>_<结束年月>.csv
```

**示例**：
- 钢筋_北京_2020-01_2024-12.csv
- 水泥_上海_2021-01_2024-06.csv
- 混凝土_C30_广东_2022-01_2024-12.csv

**字段填写规则**：
- 材料名：中文（如「钢筋」「水泥」「混凝土」），如果是混凝土请标注强度等级（C30/C40 等）
- 地区代码：北京/上海/广东/江苏/全国等
- 起始/结束年月：YYYY-MM 格式

---

## 2. CSV 字段规范（最少 3 列）

### 最小字段集（必须）

```
date,price,material
2020-01-15,4250,钢筋
2020-02-15,4180,钢筋
2020-03-15,4120,钢筋
...
```

字段说明：
- `date`：日期，YYYY-MM-DD 格式（统一用每月15日作为代表日）
- `price`：价格，单位必须是「元/吨」或「元/立方米」（取决于材料）
- `material`：材料名称（与文件名保持一致）

### 推荐字段集（推荐）

```
date,price,material,unit,region,source
2020-01-15,4250,钢筋,元/吨,北京,北京造价信息网
2020-02-15,4180,钢筋,元/吨,北京,北京造价信息网
```

字段说明：
- `unit`：单位（元/吨 / 元/立方米 / 元/平方米）
- `region`：地区
- `source`：数据来源 URL（方便在 README 引用）

### 完整字段集（最优）

```
date,price,material,unit,region,source,category,spec
2020-01-15,4250,钢筋,元/吨,北京,北京造价信息网,主材,HRB400 Φ16-25
```

额外字段：
- `category`：分类（主材/辅材/机械/人工）
- `spec`：规格（HRB400 / C30 / 42.5 等）

---

## 3. 数据质量要求

```
✅ 时间连续性：每月一条记录，不允许跨月缺失超过 2 个月
✅ 价格合理性：单月价格变动不超过 30%（超过 = 检查数据）
✅ 数值格式：纯数字（不要带「约」「元」等单位文字）
✅ 日期格式：YYYY-MM-DD（用 Excel 的「设置单元格格式 - 日期」统一）
✅ 单位统一：同一种材料用同一单位（不要一列钢筋既有元/吨又有元/千克）
```

如果下载的数据有缺失或异常：
- 在文件名加 `_fixme` 后缀（如 `钢筋_北京_2020-01_2024-12_fixme.csv`）
- 在 docs/data_quality_issues.md 里说明缺失/异常情况

## 6. 数据下载优先级（先做哪个）

**第 1 优先**：1 种材料 × 1 个地区 × 5 年数据（用来跑通整个 pipeline）
- 推荐：钢筋 + 北京/上海 + 我的钢铁网/兰格钢铁网

**第 2 优先**：扩展到 3-5 种材料（钢筋/水泥/混凝土/砂石/木材）
- 推荐数据源：北京造价信息网 / 上海造价信息网

**第 3 优先**：多地区对比（北京 vs 上海 vs 广东）

## 7. 字段填写示例（Excel 操作步骤）

如果你是 Excel 下载的数据：

1. 新建一列叫 `date`，第一格填 `2020-01-15`，下拉填充到所有行
2. 新建一列叫 `price`，把原始价格列复制过来（去掉单位文字）
3. 新建一列叫 `material`，所有行填同一种材料名
4. 新建一列叫 `unit`，所有行填同一单位
5. 新建一列叫 `region`，所有行填同一地区
6. 新建一列叫 `source`，所有行填数据来源 URL
7. 「另存为」→ CSV UTF-8 格式

完成后文件名按规范命名，放进 `data/raw/` 目录。
